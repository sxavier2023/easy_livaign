A real-time shared living management app that helps people organize houses, tasks, chat, inventory, and members in one place.

🚀 Overview

HouseFlow is a full-stack cross-platform application built to simplify shared living.

It allows users to:

Create or join a shared house
Communicate in real time
Manage household tasks
Track shared inventory
Manage members and roles

This project focuses on solving real-world coordination problems in shared apartments (WG / flatshares).

✨ Features
🏡 House Management
Create a new house/room
Join existing houses via invite

👥 Members System
View all house members
Role-based structure (admin/member)
